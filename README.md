#protected_routing_v2

This project is an upgraded version of "protected_routing" that moves it from Next.js v14 to Next.js v16. Breaking changes include: filename change for "middleware.tsx" to "proxy.tsx" and a change of dynamic route parameters(params, searchParams) inside layout.tsx and page.tsx from synchronous to asynchronous, meaning we must await them before reading the parameters. Other than that, the project largely remains the same, covering concepts such as how to protect routes using proxy in Next.Js + handling cookies both client side & server side etc.
